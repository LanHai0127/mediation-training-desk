# 调解台 · 场景与人物建模提示词

> 用途：把本项目的 7 个微缩场景、1 个主角、14 个固定站位人物，写成可直接交给 3D 生成工具/建模师的提示词。
> 每条场景提示词**自成一段**，复制即可用；人物单独出模型，场景里不放人物。
> 统一规格见 §1，不符合规格的资产不进场景。

---

## §1 统一规格（先定死，否则七个场景摆不到一起）

| 项 | 规格 |
|---|---|
| 底座 | 正方形，边长 **600 mm**，厚度 60 mm，边缘 2 mm 倒角 |
| 地形 | 地面最高点距底座顶面不超过 **35 mm**（建筑、树不算） |
| 比例 | **1:35**（主角与成人 NPC 身高 45~48 mm） |
| 坐标原点 | 底座左下角，X 向右、Z 向里、Y 向上，单位 mm |
| 光照 | 单主光（低角度侧逆光）+ 环境天光；**不烘死阴影**，留实时投影 |
| 渲染 | 三渲二（Cel Shading）：2~3 阶色阶贴图 + 屏幕空间描边，描边粗细 1.2~1.8 px @1080p |
| 材质 | 哑光塑料为主，玻璃/水面用透明树脂质感；**禁止照片级 PBR 反照率** |
| 导出 | glTF 2.0（.glb），Y 轴向上，贴图 2K（主角 4K），合并同材质 |
| 面数 | 单场景 8~15 万三角面；主角 1.5~2 万；单个 NPC 6~8 千 |
| 命名 | `env_<场景>_<物件>`、`char_<角色>_<部件>`，全小写 |
| 文字 | 招牌用风格化假名/变形汉字，**不得出现真实商标、真实警务标识、真实单位名** |
| 人物 | 场景模型内**不含任何人物**；人物单独建模、按 §5 坐标摆位 |

**七个场景拼在一起应像同一个虚构小镇（城西）的一天**：清晨的院墙 → 上午的值班台 → 黄昏的球场 → 傍晚的村委会 → 深夜的居民楼。共用建筑语汇：白墙灰瓦、蓝色卷帘门、梧桐、水泥路沿、黄色路牙石。

```
薄荷绿 #9CC5B4   靛青   #2F4858   暖灯黄 #FFD08A

```
