## §0 要产出的东西长什么样

| 项 | 规格 |
|---|---|
| 形态 | 一块**可自由拖拽、旋转、缩放**的三维微缩底座，像一件摆得上桌的收藏模型 |
| 技术 | three.js **0.180**（`three` + `addons/controls/OrbitControls.js`），ES module |
| 交付 | 首选单文件 HTML（three 内联，双击即开）；也接受 vite 工程（`src/main.js` + `index.html`） |
| 界面 | 画面里**没有任何 UI**：无按钮、无面板、无水印、无坐标轴、无调试网格 |
| 视角 | 默认等距俯视（仰角约 36°），OrbitControls 绕 Y 轴 360°、俯仰 10°~80°、缩放 0.6~2.5 倍 |
| 底座 | 正方形，边长 **20 世界单位**，厚 0.55，侧面深色，边缘 0.04 倒角 |
| 坐标 | 底座中心为原点，Y 向上，X 向右，Z 向观察者；可站立区域 X/Z ∈ [-9.2, 9.2] |
| 比例 | 1 单位 ≈ 0.5 m；成人身高 1.7 单位 |
| 面数 | 单场景 3~8 万三角面；桌面 60fps、手机 30fps |
| 体积 | 单文件 < 900 KB（three 内联约 650 KB + 场景代码） |
| 资源 | **零外部请求**：不引 CDN、不加载贴图/模型文件；纹理用 canvas 现画 |
| 兼容 | 触摸可拖拽/双指缩放；页面无滚动条；`touch-action: none` |

## §1 通用系统段（每个场景都先粘这段，定调）

```
你是一名 three.js 场景工程师。请产出一个可直接运行的三维微缩场景页面，风格为三渲二卡通风。

【技术约束，逐条遵守】
1. three@0.180，ES module；相机 PerspectiveCamera(fov 38)；OrbitControls 开启 damping，
   禁止平移（enablePan=false），极角限制 10°~80°，缩放 0.6~2.5。
2. 全部用程序化几何拼装（Box / Cylinder / Sphere / Plane），不加载任何外部模型或贴图。
   需要文字、招牌、海报时，用 canvas 画好当贴图。
3. 材质统一 MeshToonMaterial（三渲二），低饱和；玻璃用透明材质（opacity 0.35~0.6，
   depthWrite:false）；水面用两层半透明叠色 + 轻微扰动。
4. 光照：暖色主光（DirectionalLight，投射阴影，shadow map 2048）+ 冷色补光 +
   半球/环境光提亮暗部；renderer 开 ACESFilmicToneMapping，曝光 0.9~1.0。
5. 加 FogExp2（密度 0.006~0.01），让远景收进底座，别像"漂在虚空里"。
6. 底座：正方形 20×20，厚 0.55，侧面深一号色；底座之外什么都不放。
7. 单场景三角面 ≤ 8 万；动画只做"循环的、克制的"微动，用 clock 驱动，不引第三方库。
8. 不要出现任何 UI：无按钮、无面板、无 loading 文字、无坐标轴、无水印。
9. 代码组织：写几个辅助函数（box/cyl/sph/plane/label/toon）压缩重复拼装；
   动画统一收进一个 animated 收集器，在 render loop 里按时间推进。
10. 交付一个完整文件，我复制就能跑。

【美术总则】
- 干净、通透、可爱但不幼稚；哑光塑料 + 少量玻璃与金属反光，像"涂装好的树脂模型"。
- 每场景一个主色 + 一个对比色 + 中性灰白；不要满屏高饱和。
- 边缘要有轮廓感（深一号的同色描边几何，或靠明暗对比），不必上后处理。
- 光比要软：主光 1.6~2.4，补光 0.8~1.3，环境 0.5 左右，阴影不做死黑。
```

【底座与构图】正方形底座上，房间占约 70%，右后方留一条短走廊（尽头是通往调解室的门），

## §3 场景切换与镜头

| 项 | 规定 |
|---|---|
| 单场景单文件 | 每个场景一个 HTML，通过 `?scene=duty` 或父页面 postMessage 切换，不把七个场塞进一个文件 |
| 初始镜头 | 等距俯视：目标点 (0, 0.6, 0)，相机距离 26，方位角 45°，仰角 36° |
| 交互 | 左键拖拽旋转、滚轮/双指缩放；**禁止平移**（否则模型会被拖出画面） |
| 过渡 | 换场景时相机从上一机位 lerp 到默认机位（0.6 秒），不硬切 |
| 选中反馈 | hover 只做"轻微提亮/描边"，不弹窗、不出文字气泡 |

### 4.1 主角 · 民警小陈（唯一可移动角色）

```
【角色】一个三渲二低模人物，身高 1.7 单位，站在底座上要能立刻看出"是民警"，但不得有任何真实警徽。

【外形】男，28 岁，偏瘦结实，短发；深蓝执勤外套（拉链半开）+ 深色长裤 + 软底皮鞋；
左胸一块空白矩形布章，左臂一块素色臂章；腰侧挂钥匙串。手里可拿一部手机（可切换收起）。

【构造方式】程序化拼装即可，不需骨骼：躯干用圆角长方体，头用球体，四肢用胶囊/圆柱，
用一个 pivot 组控制摆臂与走路；坐姿用另一套角度预设。

【动作】待机（呼吸起伏 + 重心左右微移）、行走（手臂前后摆、步幅小、身体略前倾）、
停下转身、查看（俯身或举手机，2 秒）、抬手示意（一次性）。

【移动规则】在场景可站立网格上做 A*（格 0.5 单位，斜走不切角）；
点击地面 → 走过去；点击人物/物件 → 走到交互距离（2.2 单位）后触发；
人物半径 0.45 单位，不穿家具；Y 始终贴地；镜头只做轻微跟随（死区 3 单位），不自动绕人转。

【避免】真实警徽、警号、单位标识、写实皮肤、夸张表情。
```

## §5 动效清单（幅度克制，全部循环）

| 类 | 做法 | 幅度 |
|---|---|---|
| 灯 | 点光源强度按正弦微调 | ±2% |
| 风 | 树叶、电线、海报边角、窗帘 | 摆动角 ≤ 3° |
| 水 | 水面 UV 缓慢偏移；浪花用半透明白色片往返 | 周期 6~9 秒 |
| 滴落 | 屋檐/空调冷凝水：小球下落 → 消失 → 涟漪圆环扩散 | 3 秒一次 |
| 机械 | 风扇旋转、秒针跳格、指示灯呼吸 | 各自固定节奏 |
| 尘埃/雾 | 贴地薄雾片缓移 | 速度 ≤ 0.02 单位/秒 |

**禁止**：粒子爆炸、镜头摇晃、色温突变、随机闪烁（会被当成 bug）。

## §6 与现有训练台的接入方式

业务层（判定 / 对话 / 手机 / 复盘 / 电话）**全部保留**，只替换「场景渲染」这一层：

```
┌─────────────────────────────┐
│ 训练台页面（现有）           │  方案区 / 对话坞 / 卷宗 / 手机 / 复盘
│  ┌───────────────────────┐  │
│  │  <iframe> 3D 场景页    │  │  three.js 微缩场景（本文件产出的东西）
│  └───────────────────────┘  │
└─────────────────────────────┘
        ↕ postMessage 事件桥
```

事件桥（先定死，再实现）：

| 方向 | 消息 | 载荷 |
|---|---|---|
| 页面 → 场景 | `scene:load` | `{caseId, sceneId, characters:[{id,name,x,z,facing,pose}]}` |
| 页面 → 场景 | `actor:move` | `{x, z}`（点地面下发，场景内做 A*） |
| 页面 → 场景 | `actor:teleport` | `{x, z, facing}`（换场景时直接落位） |
| 页面 → 场景 | `spot:highlight` | `{ids:[]}`（看过的点位轻微提亮） |
| 场景 → 页面 | `scene:ready` | `{}` |
| 场景 → 页面 | `actor:arrived` | `{x, z}` |
| 场景 → 页面 | `spot:click` | `{id}` |
| 场景 → 页面 | `person:click` | `{id}` |

替代方案（更省事）：把场景做成 ES module 直接 `import` 进现有页面，用一个 div 挂载。
**注意**：现有 CSP 是 `script-src 'self'`，模块必须同源；iframe 方案则要单独放行 `frame-src`。

## §7 验收（每个场景都要过）

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 双击 HTML 就能看，无外部请求 | 断网打开，控制台无 404 |
| 2 | 能 360° 旋转、缩放、不能平移出画面 | 拖一圈，底座始终在视野内 |
| 3 | 台面/地面透视正确，没有悬空物件 | 转到侧面看，物件都落在底座上 |
| 4 | 60fps（桌面）/ 30fps（手机） | Chrome 性能面板 + 真机 |
| 5 | 画面里没有任何 UI | 截图肉眼过一遍 |
| 6 | 三角面 ≤ 8 万、单文件 ≤ 900KB | `renderer.info.render.triangles` + 文件大小 |
| 7 | 光照冷暖分明、主体不糊 | 与参照场景对照色调 |
| 8 | 动效幅度克制 | 静看 10 秒，没有跳变 |
