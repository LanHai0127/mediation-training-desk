# 调解台 · 3D 微缩场景提示词（v3 · 细节版）

> **v3 变更（2026-11-03）**：主题从「2.5D Canvas 地图」改成「three.js 三维微缩场景」；本版重点补**细节密度**、
> **户内装饰**与**户外景物**，并放开**非关键 NPC**（氛围人物）。旧版见 `docs/archive/`。
>
> 每条提示词都可整段复制，产出的是**能跑、能走、能点的 three.js 场景**，不是给美术的描述稿。
> 判定、对话、手机、复盘、电话这些业务层不动，只换渲染与场景表达。

## §0 要产出的东西

| 项 | 规格 |
|---|---|
| 性质 | **可玩的游戏场景**：第三人称主角、点击寻路、可交互点位、相机跟随 |
| 形态 | 一块**可绕看、缩放**的三维微缩底座，像摆得上桌的收藏模型 |
| 技术 | three.js **0.180**；交付单文件 HTML 或（工程）`index.html + src/main.js` |
| 界面 | 场景里**没有任何 UI 面板**；只允许游戏内反馈（选点圈、目标高亮、头顶名牌） |
| 视角 | 默认等距俯视（仰角 36°），可拖拽绕 Y 轴 360°、俯仰 10°~80°、缩放 0.6~2.5 |
| 底座 | 正方形 20×20 世界单位，厚 0.55，侧面深色，边缘 0.04 倒角 |
| 坐标 | 底座中心为原点，Y 向上；可站立区 X/Z ∈ [-9.2, 9.2] |
| 比例 | 1 单位 ≈ 0.5 m；成人 1.7 单位 |
| 面数 | 单场景 5~12 万三角面；桌面 60fps、手机 30fps |
| 体积 | 单文件 < 1.2 MB（three 内联 ≈ 650 KB + 场景代码） |
| 资源 | **零外部请求**：不引 CDN、不加载贴图/模型；纹理用 canvas 现画 |
| 兼容 | 触摸可拖拽/双指缩放；无滚动条；`touch-action: none` |

## §1 通用系统段（每个场景先粘这段）

```
你是一名 three.js 场景工程师，请产出一个可直接运行的三维微缩场景，风格为三渲二卡通风。
这不是观赏模型，是一个能操控主角在里面走动的游戏场景。

【技术约束，逐条遵守】
1. three@0.180，ES module；PerspectiveCamera(fov 38)；OrbitControls 开 damping，
   禁平移（enablePan=false），极角 10°~80°，缩放 0.6~2.5。
2. 全部程序化几何（Box / Cylinder / Sphere / Plane / Torus / Cone），不加载任何外部模型或贴图；
   文字、招牌、海报用 canvas 画好后作贴图。
3. 材质统一 MeshToonMaterial（三渲二），低饱和；玻璃透明（opacity 0.35~0.6，depthWrite:false）；
   水面用两层半透明叠色 + 轻微扰动；金属用略高光。
4. 光照：暖主光（DirectionalLight，投阴影，shadow map 2048）+ 冷补光 + 半球光；
   ACESFilmicToneMapping，曝光 0.9~1.0；光比要软，阴影不死黑。
5. FogExp2（密度 0.006~0.01），让远景收进底座。
6. 底座：20×20、厚 0.55，侧面深一号；底座外什么都不放。
7. 单场景 5~12 万三角面；动画只做"循环的、克制的"微动，clock 驱动，不引第三方库。
8. 没有任何 UI：无按钮、无面板、无 loading 文字、无坐标轴、无调试网格、无水印。
9. 代码组织：box/cyl/sph/plane/label 几个辅助函数压重复；动画收进一个 animated 收集器。
10. 交付完整文件，我复制就能跑。

【可玩性，优先级最高——没有它这个场景就是废的】
A. 必须有一个玩家可操控的主角（第三人称），能在地面行走。
B. 点地面 → 沿 A* 走过去（绕开家具，不穿墙）。
C. 点物件/人物 → 走到交互距离（2.2 单位）后**才**触发，不隔空触发。
D. 可交互物件要有热区，hover 轻微提亮；不可交互的东西不许做成"可点"。
E. 相机跟随主角（死区 3 单位）；拖拽可临时绕看，松手 2 秒缓慢回正。
F. 手机能玩：单指点击移动、双指缩放、拖拽旋转。

【美术总则】
- 干净、通透、有生活气；哑光塑料 + 少量玻璃与金属反光，像"涂装好的树脂模型"。
- 每场景一个主色 + 一个对比色 + 中性灰白；不要满屏高饱和。
- 光比要软：主光 1.6~2.6，补光 0.8~1.3，环境 0.4~0.6。
- **细节要多、但不能乱**：一个视觉中心、两三个次中心，其余都往后退（降饱和、压对比）。
```

## §1.2 可玩性规格

### 一、主角与移动

| 项 | 规格 |
|---|---|
| 表示 | 一个 Group：躯干 + 头 + 四肢；脚底 origin 在 (0,0,0)，Y 贴地 |
| 站立 | 高 1.7；行走时上下起伏 0.04，摆臂 ±0.5 rad |
| 输入 | 左键/单指点地面 → 目标点；点人物/物件 → 该物体的交互点 |
| 寻路 | 0.5 单位网格（36×36），A* 八向，斜走要求两正交格都通；**结果要拉直**（共线合并 + 视线检测） |
| 碰撞 | 障碍登记 AABB（x,z,w,d），膨胀 0.45 后标不可走 |
| 移动 | 速度 2.6~3.4 单位/秒；朝向按速度方向平滑旋转（每帧 ≤8°） |
| 到达 | 距目标 < 0.15 判定到达，清空路径并回调 `actor:arrived` |
| 卡住 | 目标在障碍内 → 吸附最近可走格；无路 → 不动 + 回调 `actor:blocked` |

### 二、交互

| 项 | 规格 |
|---|---|
| 拾取 | Raycaster 对 pickable 组命中；人物用放宽的球形热区（0.6） |
| 走近 | 命中后先送主角到 `interactPoint`，到位才触发 |
| 距离 | 交互距离 2.2；超出只走位，不触发 |
| 反馈 | hover：emissive +12%；选中：脚下 0.5 半径半透明圆环 |
| 事件 | 回调 `spot:click {id}` / `person:click {id}`；不在场景里弹文字 |

### 三、相机

| 项 | 规格 |
|---|---|
| 初始 | 距离 22~26，仰角 36°，方位角 45°，目标 = 主角 + (0, 0.9, 0) |
| 跟随 | 目标点 lerp 0.08；死区 3 单位 |
| 手动 | 拖拽绕主角旋转；滚轮/双指 8~30 |
| 回正 | 松手 2 秒后方位角/仰角缓慢回正 |
| 限制 | 相机不得低于地面 1.2，避免钻进地板 |

## §1.3 细节密度（这一版的核心要求）

> 参考标准：一块"摆得上桌的收藏模型"，**任意一个视角看过去都不该有空墙、空桌面、空地面**。

### 数量基准（低于这个数就是没做完）

| 场景类型 | 可辨识物件 | 其中"凑近才看得见"的小物 |
|---|---|---|
| 室内（值班室 / 调解室 / 居家） | **≥ 45 件** | 每人 5~8 件（耳塞、药盒、笔、杯垫、便签…） |
| 室外（球场 / 村院 / 单元门外 / 院墙） | **≥ 35 件** + 6 处环境细节 | 每景 3~5 件（烟头、蝼蚁、落叶堆、车辙、蛛网） |

### 六个层次（每层都要有东西，缺一层就"空"）

| 层 | 室内该有什么 | 室外该有什么 |
|---|---|---|
| 结构 | 地砖/木地板、墙裙、吊顶、门、窗、栏杆 | 地面材质、路牙、围网、排水沟、台阶 |
| 家具 | 桌、椅、柜、沙发、饮水机、风扇 | 长椅、垃圾桶、灯杆、宣传栏、车 |
| 桌面 | 纸张、笔筒、杯子、印泥、便签、台灯 | 保温杯、球、工具、塑料袋 |
| 墙面 | 公示栏、挂钟、日历、开关、照片 | 门牌、通知、小广告、电箱 |
| 角落 | 扫把、纸箱、灭火器、雨伞架、拖鞋 | 水泥袋、砖堆、水缸、柴垛、旧盆 |
| 环境 | 灰尘感、光斑、地垫、地面反光 | 水洼、落叶、草簇、车辙、雾 |

### 三条硬规矩

1. **视觉中心只给一个**：桌/球场/院墙是主角，其余细节都要压低对比（降饱和 10~20%）。
2. **每件小物都要有"为什么在这"的理由**：登记簿旁必然有笔、水杯旁必然有杯垫、烟灰缸旁必然有打火机。
3. **允许一点"人刚离开"的痕迹**：椅子半拉、被子没叠、水杯还有水、烟头没掐。这比多摆十件家具更有生活气。

### S0 · 派出所值班室（上午 09:10）

```
【场景】虚构小镇派出所的值班室，整个训练台的入口。

【底座与构图】正方形底座，房间占约 70%，右后留一条短走廊（尽头一扇通往调解室的门），
左前是双开玻璃门门厅。视觉中心是一张 L 形值班台（主台靠右、侧台向左伸），台后一把转椅半拉开。

【结构】水磨石地砖带铜条分格、0.9 高墙裙、格栅吊顶两排、后墙一扇磨砂玻璃窗、双开玻璃门带闭门器、
走廊口一道拱形门套、踢脚线、墙角插座。

【家具】L 形值班台、台后转椅（椅背搭一件外套）、访客长椅、靠墙三连等候椅、两台文件柜、
饮水机（水桶半满、下方接水盘）、立式风扇、双桶分类垃圾桶、雨伞架（三把伞）、拖把桶与拖把、
门口堆三只快递纸箱、失物招领架（挂着两把钥匙和一只伞）。

【桌面与墙挂】台面：显示器（屏幕是警情列表的抽象色块）、键盘、座机（听筒微微离座）、
对讲机充电座（两台，指示灯一绿一灭）、摊开的接警登记簿、笔筒插三支笔、印泥盒、老花镜、
便签本、胶带座、一次性纸杯叠（五个）、半杯水、台灯、便民服务牌（放大镜/充电线/老花镜）。
墙上：警情公示栏（四色便签 + 图钉）、值班表（手写格）、挂钟、电箱、灭火器、两张宣传画（抽象）、
挂历、一块小白板（今日警情，抽象字）。

【角落与小物】地垫（"出入平安"抽象字）、门后挂钩、墙角纸屑两片、网线沿墙根走、
暖气片、窗台上的绿萝、走廊尽头一盏感应灯。

【氛围人物（不交互）】① 一位抱着布袋的老太太坐在三连椅上等（低头看手里的号票）；
② 一个穿夹克的年轻人站在走廊口打电话（背对镜头，一手捂耳）。

【时间与氛围】上午九点，天光从磨砂玻璃与玻璃门透进来，室内两排灯管偏冷白补光；
地面有柔和反光，空气干净，像刚交接完班。

【材质与渲染】三渲二；水磨石哑光带颗粒，桌面木纹克制，金属柔和银灰，玻璃半透明。
色调：警蓝 #2F4A6D + 奶油白 #F5EFE3 + 水泥灰 #B9B4AC。

【动效】挂钟秒针一格一格走；显示器状态点缓慢闪烁；对讲机指示灯呼吸；地垫边角被穿堂风掀起；
吊顶灯管极轻微呼吸；走廊感应灯偶尔亮起再灭。

【可行走与交互】可走：值班台前、门厅、等候区（约 7×6 单位）。障碍：值班台、文件柜、饮水机、
长椅、纸箱堆。可交互：座机（走近拨号）、值班台（翻登记簿）、公示栏（看通报）、门（去调解室）、
失物架（看看有什么）。

【避免】真实警徽与真实单位名称、乱码文字、UI、水印、过曝、把细节堆成一团乱麻。
```

### S2 · 302 室 · 报警人家中（深夜 21:40）

```
【场景】老式两居室的客厅，虚构小镇一栋六层居民楼的三层。切开后墙做剖面。

【底座与构图】客厅占底座大半。视觉中心是沙发 + 茶几组成的休息角；次中心是右侧餐桌与后墙窗。

【结构】浅色木地板（有磨损与两处划痕）、0.8 墙裙、吸顶灯、后墙窗（窗帘半拉）、
入户门（半开，门外楼道更暗，门后挂一件护士服）、踢脚线、墙角一处水渍印。

【家具】三人沙发（坐垫塌了一角）、薄毯（半塌在扶手）、抱枕两只、茶几、电视 + 电视柜、
四人餐桌 + 四把椅子（两把推回去、一把歪着）、鞋柜（柜门有一条缝）、小冰箱（厨房口）、
折叠晾衣架（搭着两件衣服）、儿童玩具收纳箱（盖没盖严）。

【桌面与墙挂】茶几：耳塞盒（空的，只剩两只）、手机（屏幕亮着录音界面）、遥控器、
半杯水 + 杯垫、药盒（打开，几粒药倒在盖子上）、纸巾、充电线绕成一团、外卖盒 + 一双筷子。
餐桌：吃到一半的盒饭、筷子架、一个苹果、果盘、孩子的作业本与铅笔。
墙上：挂钟（九点四十）、家庭合影三张（人脸抽象）、日历（圈了几天）、开关面板、
墙上挂钩（挂着一串钥匙）、暖气片。

【角落与小物】绿萝两盆（一盆叶子发蔫）、落地灯（关着）、散在地上的三块积木、
一双平底护士鞋、玄关的书包、门口两只快递箱、沙发缝里露出一角毛毯、
窗台上的半瓶矿泉水、阳台口的拖把。

【氛围人物（不交互）】一只橘猫蜷在沙发扶手上睡着（尾巴偶尔动一下）——不是人，但让屋子"有人住"。
```

| 姿态 | 只做 1~2 个微动（呼吸、低头看手机、抽烟的手、尾巴摇），不做位移 |
| 位置 | 放在边缘或背景层，距主通路 ≥ 2 单位；不站在门口/桌前等关键路径上 |
| 颜色 | 比关键人物低饱和 15~20%，不与主角色撞色 |
| 尺寸 | 与关键人物一致，不缩小（缩小会显得像摆件） |
| 名单 | S0 抱布袋的老太太、走廊口打电话的年轻人；S1 门口抱文件袋的中年男；S3 蹲着抽烟的工装男、牵狗的阿姨；S4 压腿的老人、骑车的学生、抱孩子的年轻妈妈；S5 择菜的妇女、下棋的两个老人；S6 端盆倒水的妇女、蹲着拔菜的老人 |
| 动物 | 允许（S2 沙发上的橘猫、S5 鸡笼里两只鸡、S3 一条小狗）——它们比人更能表现"生活气" |

## §5 动效清单（克制、循环）

| 类 | 做法 | 幅度 |
|---|---|---|
| 灯 | 点光强度正弦微调 | ±2% |
| 风 | 树叶、电线、海报边角、窗帘、晾衣 | 摆角 ≤ 3° |
| 水 | 水面 UV 偏移；浪花/积水用半透明片往返 | 周期 6~9 秒 |
| 滴落 | 屋檐/龙头：小球下落 → 涟漪圆环扩散 | 3 秒一次 |
| 机械 | 风扇、秒针、指示灯、猫呼吸、鸡啄食 | 各自固定节奏 |
| 雾 | 贴地薄雾片缓移 | ≤ 0.02 单位/秒 |

**禁止**：粒子爆炸、镜头摇晃、色温突变、随机闪烁（会被当成 bug）。

## §6 与训练台的接入

```
┌─────────────────────────────┐
│ 训练台页面（现有）           │  方案区 / 对话坞 / 卷宗 / 手机 / 复盘
│  ┌───────────────────────┐  │
│  │  <iframe> 3D 场景页    │  │  three.js 微缩场景
│  └───────────────────────┘  │
└─────────────────────────────┘
        ↕ postMessage 事件桥
```

| 方向 | 消息 | 载荷 |
|---|---|---|
| 页面 → 场景 | `scene:load` | `{caseId, sceneId, characters:[{id,name,x,z,facing,pose}]}` |
| 页面 → 场景 | `actor:move` | `{x, z}` |
| 页面 → 场景 | `actor:teleport` | `{x, z, facing}` |
| 页面 → 场景 | `spot:highlight` | `{ids:[]}` |
| 场景 → 页面 | `scene:ready` / `actor:arrived` / `spot:click` / `person:click` | 各自 id 或坐标 |

> ⚠ **CSP 坑（已踩）**：现有页面 CSP 是 `script-src 'self'`，**内联脚本会被直接拦掉**。
> 场景脚本必须外链（`<script type="module" src="./duty.js">`），否则页面一片空白，
> 控制台只有一行 CSP 拒绝，很容易误判成"three 加载失败"。iframe 方案需单独放行 `frame-src`。

### 参考实现（已跑通）

| 文件 | 作用 |
|---|---|
| `src/web/scenes/scene3d.js` | 运行时：底座/光/雾、A*（0.5 格、不切角、视线拉直）、碰撞膨胀、主角、相机、Raycaster |
| `src/web/scenes/duty.js` | S0 值班台场景数据（家具、交互点、障碍） |
| `src/web/scenes/duty.html` | 布局 + 外链脚本（符合 CSP） |
| `src/web/scenes/vendor/three.*.js` | three 0.180 本地副本 |

## §7 验收

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 双击/直链能开，无外部请求 | 断网打开，控制台无 404 |
| 2 | 能 360° 旋转、缩放、不平移出画面 | 拖一圈，底座始终在画面里 |
| 3 | 无悬空物件 | 转到侧面看，所有东西都落在底座上 |
| 4 | 60fps 桌面 / 30fps 手机 | 性能面板 + 真机 |
| 5 | 画面里无 UI | 截图肉眼看 |
| 6 | 三角面 ≤ 12 万、单文件 ≤ 1.2MB | `renderer.info` + 文件大小 |
| 7 | 冷暖分明、主体不糊 | 截图对照色调 |
| 8 | 动效克制 | 静看 10 秒，没有跳变 |
| 9 | **能走** | 点桌子另一侧，人绕过去而不是穿过去 |
| 10 | **走近才触发** | 隔半场点人物，事件不应立刻触发 |
| 11 | **不卡死** | 连点十几个点，人都能回来 |
| 12 | **相机跟得住** | 拖到侧面等 2 秒回正 |
| 13 | **细节密度达标** | 截图数物件：室内 ≥45、室外 ≥35，且六层都有 |
| 14 | **没有空墙/空桌面/空地面** | 每隔 90° 截一张，逐张看 |
| 15 | 氛围人物不挡路、不响应点击 | 点他们只会走过去 |
